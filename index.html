Sistem Informasi Data Mahasiswa - Praktikum 1 - Kelas B

Sistem ini merupakan aplikasi pengelolaan data mahasiswa kelas B yang digunakan untuk menampilkan daftar mahasiswa aktif dan menambahkan data mahasiswa baru.

  • Informasi Aplikasi
  • Daftar Mahasiswa
  • Tambah Mahasiswa Baru

Informasi Sistem

Sistem ini dibuat untuk memenuhi tugas praktikum 1 mata kuliah Sistem Informasi. Aplikasi ini berisi data mahasiswa kelas B, yang berisi nama, NPM, kelas, mata kuliah, dan dosen pengampu.

Informasi Sistem

Sistem ini dibuat menggunakan bahasa pemrograman HTML, CSS, dan JavaScript. Aplikasi ini juga menggunakan framework Bootstrap untuk mempercantik tampilan aplikasi.
